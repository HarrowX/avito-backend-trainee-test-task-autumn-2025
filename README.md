# Тестовое задание для стажёра Backend (осенняя волна 2025)

## Инструкция по запуску

### Скопируйте и настройте .env
```bash
  cp .env.example .env
```
### Запустите окружение в docker compose (убедитесь в запущенном docker daemon)
```bash
  docker compose up -d
```

### Запуск приложения
```bash
  docker compose up -d
```

Предоставленно следующее [api](http://localhost:8080/swagger-ui/index.html)

### Выключение окружения
```bash
  docker compose down
```

# Принятые решения
1. Использование стека kotlin, spring boot 3 (mvc, jpa, etc...).
2. Создание простейшего монолитное приложение без DDD (spring-modulith), учитывая дедлайн 16.11.2025
3. Интегрирование предоставленный openapi.yml файл, обернуть в swagger-ui
4. DB-first подход, создадим миграции к бд, следовательно подключение liquebase



# Проблемы
1. Была проблема с отсутствием поддержки у kotlin jdk версии 25, при том что gradle начиная с версии 9.1.* имеет поддержку. Решение - переход на jdk 21.
